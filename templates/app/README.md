## Getting started

```bash
bun install
cp .env.local.example .env.local   # ERP_BASE_URL + ERP_API_KEY when wiring ERP
bun run dev
```

| Command | What |
| --- | --- |
| `bun run dev` / `build` / `start` | Next.js |
| `bun run typecheck` | `tsc --noEmit` |
| `bun run check` | format:check + lint + typecheck + test |
| `bun run lint` / `lint:fix` | Oxlint (warnings are errors) + `@shadcn/lint` rules |
| `bun run format` / `format:check` | Oxfmt |
| `bun test` | Unit tests (`bun:test`) |
| `bun run schema` | Regenerate `schema.json` from `src/lib/erp/schema.ts` |
| `erp-miniapp zip [--no-check]` | Runs `bun run check`, then deploy archive → `artifacts/` |
| `erp-miniapp pack` | Whole codebase as one Markdown file for LLM context → `artifacts/` |

`bun run check` (format, lint, typecheck, tests) runs automatically: git `pre-commit` hook (installed by `bun install`), Claude Code hooks in `.claude/settings.json`, and before `erp-miniapp zip`.

Agents are instructed (see `AGENTS.md`) to **write unit tests** and **update docs in the same change** — route `docs.md`, the tables below, and the OpenWiki. Docs updates are not in CI/CD on purpose.

First time only — create the wiki. Install OpenWiki once (`npm i -g openwiki`), restart your agent, then ask it:

```text
Initialize this repository's OpenWiki from the current source and tests.
```

## Wire ERP

1. Extend `src/lib/erp/schema.ts` → `bun run schema`.
2. Replace seed reads in `lib/api/*` with `getErp()` / `erp.objects.*` (see the `erp-data` skill).
3. Switch route wrappers from `withApi` to `withErp`; keep client `api()` (initData already wired).
4. Update the page's `docs.md` status to `wired`.

## Deploy

```bash
erp-miniapp zip     # artifacts/<name>-v<version>-<yyyymmdd>.zip
```

Upload the zip to the ERP (`erp-miniapp` skill → *deploy*). The archive leaves out `node_modules`, `.next`, `.git`, `.env*`, lockfiles and agent folders; it keeps `schema.json`.

## Rules

- Import UI from `@erp/miniapp-ui` only — no local `components/ui`.
- API keys stay server-side in `lib/erp` / route handlers.
- New route → add `docs.md` + README row ([`docs/skills/page.md`](docs/skills/page.md)).
- Every behavior change ships with a unit test.
